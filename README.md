# 🔐 Login Page — Front-end Portfólio

Projeto de página de login moderna desenvolvido com **HTML**, **CSS** e **JavaScript puro**, sem frameworks ou dependências de build. Criado para demonstrar boas práticas de front-end júnior.

## ✨ Funcionalidades

- Login com validação de e-mail e senha
- Mostrar / esconder senha
- Indicador de força da senha (Fraca → Forte)
- Feedback de erro por campo
- Simulação de carregamento ao enviar
- Opção "Lembrar-me" (persiste o e-mail)
- Modo escuro / claro (respeita a preferência do sistema)
- Sessão salva no LocalStorage
- Redirecionamento automático login ↔ dashboard
- Dashboard com avatar, e-mail do usuário e horário da sessão
- Botão de logout

## 🚀 Como usar

1. Clone o repositório
2. Abra `index.html` no navegador — não precisa de servidor

```bash
git clone https://github.com/seu-usuario/login-page.git
```

## 🛠️ Tecnologias

- HTML5 semântico
- CSS3 (variáveis, animações, Grid, Flexbox)
- JavaScript ES6+ (sem frameworks)
- Font Awesome 6 (ícones via CDN)
- LocalStorage (sessão e preferências)
